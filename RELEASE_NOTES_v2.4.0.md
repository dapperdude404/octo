# AI Octopus v2.4.0 — November 2026

## Website
- Glass-inspired dark and light themes with transparent panels, teal and violet accent colors.
- Improved spacing, padding, mobile readability, button styles and responsive release cards.
- Developer portfolio, verified GitHub/social profiles and project overview.
- Dedicated release links for source ZIP, web ZIP, Android debug build workflow and the optional backend package.
- AI Octopus v2.1 source remains merged in the `main` production branch.

## Downloads and requirements
- **AI-Octopus-web-v2.4.0.zip:** static browser app suitable for GitHub Pages.
- **AI-Octopus-source-v2.4.0.zip:** repository source code at the release commit.
- **ghcr.io/dapperdude404/octo-api:v2.4.0:** Node.js backend container for deployment on your own infrastructure; requires PostgreSQL and a secret environment configuration.
- **Android debug APK:** available separately from the successful Android build in GitHub Actions; this is not a Play Store release APK.

Browser-local pattern analysis is heuristic, not validated proof of authorship. User accounts, scan history, PDF/DOCX ingestion and third-party APIs require a separately deployed backend and verified provider access. The container being packaged does not mean the backend is hosted.
